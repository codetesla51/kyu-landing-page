THE ENGINE

01. DISPATCHER

Workers execute a blocking BZMPOP on Redis to get job IDs instantly with near-zero latency, avoiding DB polling entirely.

02. SCHEDULER

A background goroutine queries Postgres to promote scheduled jobs and backoff retries directly into the Redis ready queue.

03. REAPER

If a worker panics or an instance dies OOM, the reaper detects orphaned locks in Postgres and automatically resets them.

Every job is a row.

No opaque binary blobs. Query your queue state using standard SQL.

CODE

package main

import (
    "context"
    "log"
    "github.com/codetesla51/kyu"
)

func main() {
    q := kyu.New(kyu.Config{
        DSN:         "postgres://user:pass@localhost:5432/mydb",
        RedisAddr:   "localhost:6379",
        Workers:     10,
    })

    q.Register("send_email", func(ctx context.Context, payload string) error {
        log.Printf("Email: %s", payload)
        return nil
    })

    if err := q.Connect(context.Background()); err != nil {
        log.Fatal(err)
    }

    q.Start(context.Background())
}
package main

// Enqueue immediately
jobID, _ := q.Enqueue(ctx, "send_email", `{"to": "user@example.com"}`, kyu.EnqueueOptions{
    MaxRetries: 3,
    Priority:   1,
})

// Transactional enqueue (Atomic with your DB writes)
tx, _ := db.BeginTx(ctx, nil)
defer tx.Rollback()

// INSERT INTO users...

jobID, _ := q.EnqueueTx(ctx, tx, "welcome_email", `{"user_id": 1}`, kyu.EnqueueOptions{})
tx.Commit()

Exponential Backoff

Failed jobs retry with increasing delays to protect downstream APIs.

Priority Queues

Assign integer priorities at enqueue time. High priority skips the line.

Graceful Shutdown

Intercepts SIGTERM. Finishes active jobs before killing the process.

Prometheus Ready

Native exporter. Track queue depth, rates, and failures automatically.
